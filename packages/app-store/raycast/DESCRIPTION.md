Quickly share your MeetSynq meeting links with Raycast. Requires [Raycast.com](https://www.raycast.com/) to be installed and the MeetSynq from the Raycast Store needs to be installed: https://www.raycast.com/cal/. You can create an API token in your Developer MeetSynq Settings, and then you can add the API Key by opening up the MeetSynq App in Raycast.
